Flexbox помогает вам спроектировать вашу веб-страницу так, чтобы она выглядела хорошо на любом размере экрана.

В этом курсе Вы будете использовать Flexbox для создания веб-страницы с отзывчивой фотогалереей.



Шаг 1
Начните со стандартного HTML стандарта. Добавьте декларацию DOCTYPE, элемент html, элемент head и элемент body.

Добавьте атрибут lang к открывающему метке  с en set в качестве значения.



Шаг 2
В вашем head-элементе добавьте мета-тег с name, установленным на viewport, и content, установленным на width=device-width, initial-scale=1.

Также добавьте мета-тег с charset на UTF-8.



Шаг З
В элементе head вы можете добавить заголовок title с текстом, установленным для Photo Gallery, и элемент ссылки link, чтобы добавить файл styles.css на страницу.



Шаг 4
Добавить элемент header в элемент body и назначить ему класс header.

Внутри заголовка, создать h1 с css flexbox photo gallery как текст.



Шаг 5
Ниже вашего .header - элемента заголовка, создайте новый div-элемент и назначьте ему класс .gallery. Этот div будет выполнять роль контейнера для изображений галереи.

Внутри этого элемента .gallery, создайте девять элементов img.



Шаг 6
Далее, дайте каждому img атрибут src в соответствии с его порядком в документе. Первая IMG должна иметь src of https://cdn.freecodecamp.org/curriculum/css-photo-gallery/1.jpg. Остальные должны быть такими же, за исключением замены 1 на число, которое img в документе.
