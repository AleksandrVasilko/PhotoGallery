Flexbox помогает вам спроектировать вашу веб-страницу так, чтобы она выглядела хорошо на любом размере экрана.

В этом курсе Вы будете использовать Flexbox для создания веб-страницы с отзывчивой фотогалереей.

Добавьте атрибут lang к открывающему метке  с en set в качестве значения.

Также добавьте мета-тег с charset на UTF-8.

Внутри этого элемента .gallery, создайте девять элементов img.

Затем дайте своим элементам img width 100%, padding установлено на 5px, и border установлена на 5px solid blue.



Шаг 8
Обратите внимание, как синий край изображения выходит за пределы красного края галереи. Это связано с тем, как браузеры вычисляют размер элементов контейнера.

Свойство box-sizing используется для определения этого поведения. По умолчанию используется модель content-box. При использовании этой модели, когда элемент имеет определенную ширину, эта ширина вычисляется только на основе содержимого элемента. Значения полостей и границы добавляются к общей ширине, так что элемент увеличивается для размещения этих значений.

Попробуйте установить значение box-sizing к content-box эксплицитно, с помощью глобального * селектора. В данный момент вы не увидите никаких изменений, потому что вы используете значение по умолчанию.



Шаг 9
Модель border-box sizing делает противоположное как content-box. Общая ширина элемента, включая padding и border, будет определена в виде прямой ширины. Содержимое элемента будет уменьшаться, чтобы освободить место для наполнения и границы.

Измените свойство box-sizing на border-box. Обратите внимание, как ваши синие границы теперь вписываются в красную.

Шаг 14
Flexbox - это одномерная CSS-макет, который может управлять тем, как элементы распределены и выровнены внутри контейнера.

Чтобы использовать его, дайте элементу свойство display flex. Это сделает элемент контейнером flex. Любые прямые дети flex контейнера называются flex элементами.

Создать .gallery selector и сделать его flex контейнером.



Шаг 15
Flexbox имеет основную и поперечную оси. Основную ось определяет свойство flex-direction, которое имеет четыре возможных значения:

- ряд (по умолчанию): горизонтальная ось с flex элементами слева направо
- ряд-обратный: горизонтальная ось с flex элементами справа налево
- столбец: вертикальная ось с flex элементами сверху вниз
- столбец-обратный: вертикальная ось с flex элементами снизу вверх

Примечание: Оси и направления будут отличаться в зависимости от направления текста. Показанные значения относятся к направлению текста слева направо.

Попробуйте различные значения, чтобы увидеть, как они влияют на макет.

Когда вы закончите, установите явное гибкое направление строки на элементе . gallery.



Шаг 16
Свойство flex-wrap определяет, как будут себя вести ваши flex элементы, когда контейнер flex слишком мал. Установка wrap позволит разделить элементы на следующую строку или столбец. nowrap (по умолчанию) предотвращает упаковку и сжимает при необходимости.

Сделайте так, чтобы ваши элементы переносились в следующий ряд, когда у них закончится пространство.



Шаг 17
Свойство justify-content определяет, как элементы внутри контейнера flex расположены вдоль основной оси, влияя на их положение и пространство вокруг них.

Дайте вашему .gallery свойство justify-content со значением center.



Шаг 18
Свойство align-items позиционирует flex содержимое вдоль перекрестной оси. В этом случае, если вы установили направление flex-direction для row, ваша поперечная ось будет вертикальной.

Для вертикального центра ваших изображений, дайте вашему .gallery свойство align-items со значением center.



Шаг 19
Дайте вашему . gallery свойство padding, установленное на 20px 10px, чтобы создать некоторое пространство вокруг контейнера.

Затем, дайте ему max-width 1400px и добавьте margin 0 auto для центра.



Шаг 20
Обратите внимание, как некоторые из ваших изображений искажены. Это связано с тем, что изображения имеют разные отношения. Вместо того, чтобы устанавливать соотношение сторон индивидуально, вы можете использовать свойство object-fit для определения поведения изображений.

Дайте вашему . gallery img свойство object-fit и установите его cover. Это скажет изображение заполнить контейнер img при сохранении отношения, в результате чего обрезка будет соответствовать.



Шаг 21
Ваши изображения нуждаются в некотором пространстве между ними.

Свойство gap CSS shorthand устанавливает пробелы, также известные как желобки, между рядами и столбцами. Свойство gap и его подсвойства row-gap и column-gap обеспечивают эту функциональность для flex, grid и multi-column компоновки. Вы применяете свойство к элементу контейнера.

Дайте вашему . gallery flex container свойство gap с 16px в качестве значения.



Шаг 22
Немного сгладить изображения, давая .gallery img свойство border-radius с значением 10px.



Шаг 23
Псевдоэлемент ::after создаёт элемент, который является последним дочерним элементом выбранного элемента. Вы можете использовать его, чтобы добавить пустой элемент после последнего изображения. Если вы дадите ей ту же ширину, что и изображения, она будет перемещать последнее изображение влево, когда галерея будет двухколонной. Прямо сейчас он находится в центре, потому что вы установили justify-content: center на flex container.

Пример:

Пример кода

.container::after {
  content: "";
  width: 860px;
}

Создайте новый селектор, используя::after псевдоэлемент на элементе .gallery. Добавить свойство content к пустой строке "" и 350px для свойства width.
